# Security and privacy

Do not report vulnerabilities by posting client data, CNIS, PDFs, encrypted workspaces, screenshots of a real case, tokens or credentials in public issues.

Use GitHub private vulnerability reporting when enabled on this repository. Otherwise open a minimal issue requesting a private reporting channel without sensitive details.

This is experimental desktop software. Treat imported documents and free-form text as untrusted data. A calculation is not legal advice, a certified benefit or a substitute for professional review.

See docs/PRIVACY.md for storage, backups, exports and safe issue reports. Releases are unsigned unless explicitly marked otherwise; verify published SHA-256 checksums.
