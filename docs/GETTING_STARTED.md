# Primeiros passos

1. Inicie pela versão Windows publicada em Releases ou compile o código.
2. Cadastre um cliente apenas se necessário. Use dados fictícios no primeiro teste.
3. Em Cálculos do RGPS, clique Novo cálculo e escolha entrevista guiada ou editor manual.
4. Importe um CNIS com texto extraível. PDF de imagem sem OCR não é apresentado como importado com sucesso.
5. Confira vínculos, competências, valores, moedas, datas abertas, indicadores e PRPPS. Importação não equivale a validação.
6. Confirme os parâmetros que realmente conhece. O sistema não deve presumir sexo, deficiência, benefício atual ou data de entrada com base no nome.
7. Prepare salários para revisão ou declare linhas manuais conforme a hipótese. Não descarte a origem sem justificativa documental.
8. Execute apenas após conferir as pendências. Um resultado experimental não certifica direito ou regra jurídica.
9. Salve explicitamente. Para exportar PDF, escolha cálculo, formato e modo de identificação; revise o arquivo antes de compartilhar.

## Contribuições

O editor manual permite alterar competência, valor nominal, indicadores e confirmação. O CNIS permanece fonte de origem, não uma planilha livremente sobrescrita. O editor completo de lançamentos importados e operações em lote está no roadmap; não publique esse fluxo como concluído.

## Base existente

O identificador e o diretório legado de armazenamento foram preservados para compatibilidade. Faça backup pelos controles disponíveis e mantenha a mesma conta Windows. Não apague a base para contornar erros; corrupção bloqueia gravações por segurança. Restauração automatizada ainda não está implementada.
