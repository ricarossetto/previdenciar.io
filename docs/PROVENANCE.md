# Source provenance

This is a new public source tree, not an upload of a private working directory or its historical artifacts.

## Included

- Project-authored Rust domain, CNIS parser, workspace persistence, RGPS adapter and PDF renderer.
- Author-supplied rgps-core Rust implementation with MIT declared in Cargo.toml. Original computational observations and limitation tests remain in source.
- React/Tauri interface, synthetic fixtures and adapted MIT Amicro motion primitives.
- Redistributable font files with OFL notices.

## Excluded

Private reference documents, their detailed local evidence and paths, application databases, encrypted workspaces, proprietary applications, disassembly/decompilation output, tooling installations, native user-profile captures and previous executable releases.

The personal-CNIS integration test and the private-reference hash/geometry test are kept outside this public tree. Synthetic parsing, layout and renderer tests remain public.

## Scope of the license

The root MIT notice applies to project-authored contributions. Third-party licenses and notices remain authoritative for their respective code and assets. This inventory is an engineering review, not a legal opinion or certification.

Behavioral comparison is not a claim of identity with another product. The existing numeric engine includes documented observational limitations; these are exposed rather than hidden.
